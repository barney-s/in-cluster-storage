   - Type: Docker repository

   - 6x Subsystem Container Images compiled and pushed to the newly created Artifact Registry via Google Cloud Build (Path A):

     - `agentfs-node-daemon`
     - `objectfs-controller`
     - `objectfs-node-daemon`
     - `wal-buffer`
     - `cas-node-daemon`

## Important Guidance for the Owner

Before running `deploy.sh`, please ensure the following:

1. **Verify Environment Variables**:
   - Make sure `RUNBOOK_RESOURCE_PREFIX` is set in your active terminal session. This prefix is crucial as it uniquely namespaces and labels all resources created (complying with GCP constraints).
   - If you wish to target a project other than `cnrm-barni-2`, export `GOOGLE_CLOUD_PROJECT` before running the script.
2. **Cluster Creation Time**:
   - The script creates a standard GKE cluster from scratch, which can take anywhere from **5 to 8 minutes** to fully provision. Do not interrupt the script.
3. **Google Cloud Build Integration**:
   - The script uses Google Cloud Build to compile images directly inside GCP, avoiding any dependency on local Docker daemons. All compilation logs are dumped to stdout for easy tracing.
4. **Immediate Teardown**:
   - Once your tests/verifications are complete, always execute `teardown.sh` to completely destroy the cluster, disks, and registry to avoid any ongoing GCP charges.
