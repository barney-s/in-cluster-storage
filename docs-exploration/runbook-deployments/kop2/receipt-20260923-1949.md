## What the Owner Should Read in `deploy.sh` Before Deploying

1.  **Uniform Bucket Level Access (UBLA)**:
    The deployment script automatically ensures Uniform Bucket Level Access is enabled on the Cloud Build source bucket `gs://barni-cnrm-20260529_cloudbuild`. This prevents potential HTTP 412 preconditions/authentication issues during the remote image builds.
2.  **Clean CAS Heredoc**:
    To avoid YAML conversions syntax errors (`yaml: line 19: found unknown escape character`), we removed backslash escapes from the environment variables inside the CAS daemonset configuration. The script uses single-quoted literal heredoc (`<<'EOF'`) to preserve `$ADDRESS`, `$DRIVER_REG_SOCK_PATH`, and `$NODE_ID` for direct evaluation by Kubernetes on the pods.
3.  **Strict Resource Labeling**:
    All created infrastructure resources (GKE Cluster and GAR Repository) are labeled with `repo-agent-instance=ics-kop2` to ensure proper tracking and avoid configuration collisions with other instances sharing the project.
