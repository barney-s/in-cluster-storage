### Important Notes for the Owner
Please review the following details in `deploy.sh` before executing the deployment:
1. **Dedicated Service Account Permissions**:
   The script dynamically authorizes the dedicated KOPS-created worker and control-plane service accounts with the `roles/artifactregistry.reader` role on the GCP project. This ensures secure, credential-free container pulls by the GCE nodes.
2. **Uniform Bucket Level Access (UBLA) Workaround**:
   The state bucket is created with UBLA enabled, and the active Workload Identity principal is dynamically assigned `roles/storage.admin` to prevent any authentication or GCS state modification blockages.
3. **Parallel Image Compilation**:
   Image builds are executed in parallel via remote Google Cloud Build to maximize performance and avoid overloading local compute resources.
